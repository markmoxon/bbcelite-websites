How to download and play BigLander

BigLander is a gently hacked version of the original Lander, to give the game a bigger landscape and keyboard controls, and update it to run on more modern RISC OS machines. It looks like this:

You can play BigLander in a number of ways:

  • You can play it in your browser on Archimedes Live at the following sizes:
    • Play BigLander online (12 x 10 tiles, suitable for ARM2 machines)
    • Play BigLander online (19 x 19 tiles, suitable for ARM3 machines)
    • Play BigLander online (64 x 64 tiles, suitable for a Risc PC))
    • Play BigLander online (121 x 121 tiles, suitable for a Raspberry Pi)
    Note that the last two options will run slowly, as the fastest machine in Archimedes Live is the A5000. But the game still runs, so you can enjoy the huge landscapes, albeit at a more gentle pace.
  • You can also download an ADFS disc image of BigLander that contains four different landscape sizes, ready to be played on a real machine or an emulator. The landscape sizes are suitable for playing on an ARM2, ARM3, Risc PC and Raspberry Pi.
  • BigLander can be built using the repository accompanying this website, in the big-landscape branch. If you want to play with different landscape sizes, this is the best option.

For comparison, you can also play the original Lander in your browser.

Using the keyboard
------------------

BigLander supports the same mouse controls as Lander, but it also lets you fly using the keyboard, which some people might find easier - I know I do!

There are two keyboard layouts to choose from:

  • An Elite-like key layout, which you can choose by pressing "K" while on the launchpad
  • A more typical RISC OS key layout, which you can choose by pressing "L" while on the launchpad

In each case the ship will rotate in-place to indicate that the choice has changed from mouse to keyboard.

These are the keys for each layout:

Press "Y" while on the launchpad to invert the y-axis for keyboard controls, which will swap the keys for pitching down and pulling up.

Press "U" while on the launchpad to set the y-axis controls back to normal.

Press "J" while on the launchpad to switch back to the mouse.

Pressing an option key while on the launchpad will produce a beep, so you know the change has been registered.

Top tip: Thrust away from the landing pad before rotating your ship, or your game will be very short indeed.

Release history
---------------

BigLander has had the following releases:

  • 2026-11-20 - Added additional keyboard support with a more typical RISC OS layout and the ability to invert the y-axis, added a confirmation beep to options, and added a !ReadMe to the disc
  • 2026-11-19 - Added keyboard support using an Elite-like key layout
  • 2026-11-12 - Combined all four default landscape sizes into one ADFS disc image
  • 2024-03-01 - Initial release

You can check the release date by loading the !ReadMe file from the disc. The build date is at the end.
