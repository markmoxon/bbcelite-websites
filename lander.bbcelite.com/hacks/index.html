Big Lander

A list of all the Lander hacks on this site

When exploring the source code for seminal games like Lander, one often gets to thinking about what might have been, about what still could be. The following Lander-related hacks are exactly the kinds of thing that happen when, as a coder, you decide to take the detour.

All the hacks on this page work on authentic 1980s hardware; they could all have existed back in the day. I hope you enjoy them.

Big Lander
----------

Big Lander is a gently hacked version of the original Lander, to give the game a bigger landscape and update it to run on more modern RISC OS machines.

  • About Big Lander - Lander with more tiles and huge landscapes
  • Playing Big Lander - How to download and play Big Lander
  • Technical information on how this hack works - How I extended Lander to support much larger landscapes

Lander on the ARM Evaluation System
-----------------------------------

Development of Lander started on the ARM Evaluation System attached to a BBC Micro. I have persuaded Lander to run on the original development system, so this is the first ever ARM game running on the first ever ARM chip.
