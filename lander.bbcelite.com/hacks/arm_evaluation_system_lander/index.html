Running the first ever ARM game on the first ever ARM chip

This is a video of Lander (the very first ARM game) running on the ARM Evaluation System (the very first commercially available ARM-based system):

What you are seeing here is the full version of Lander, but instead of it running on an Acorn Archimedes, it's running on an ARM Evaluation System (AES) co-processor that's attached to a BBC Master via the Tube. The AES is emulated in this clip as they are super-rare and very sought after; this video uses the MacBeeb emulator.

The AES was the development system that Acorn provided with the first batch of ARM chips, which these days we retrospectively call the ARM1. Here's the ARM1 in all its glory, inside the Acorn ARM Evaluation System:

(Photo by Peter Howkins, covered by CC BY-SA 3.0)

Lander was developed on the ARM1 using an AES and later an A500; it was released in 1987 and provided with every Archimedes. For more information, see the deep dive on Lander's origins on the ARM1.

So this is the first ever ARM game running on the first ever ARM chip. How similar it is to the environment in which David Braben developed the game is anyone's guess, but I like to think it's in the ballpark.
