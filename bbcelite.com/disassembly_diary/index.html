How I documented The Sentinel over seven long months

Between September 2025 and April 2026, I disassembled and documented Geoff Crammond's epic BBC Micro game, The Sentinel. You can see the results on the dedicated website and GitHub repository. It was a proper journey of discovery; it's fair to say that Geoff Crammond never disappoints.

People often ask me how I create my disassemblies, so for this project I kept a diary. I wrote down pretty much every step in the entire process, starting with the original game disc and ending, some seven months later, with fully documented source code, a comprehensive website and a buildable repository.

Welcome, then, to my disassembly diary for The Sentinel.

In the table below you can see the whole diary, with one entry per day. For each day you can jump to the diary entry to see what I was up to, or you can see all the code changes that I made on that day in the project's GitHub repository. If it was a particularly busy day then the GitHub links may not show all of the changes by default; if this happens, you may need to click on the "Load diff" links first.

The diary entries link through to the documented source code where possible, so you can not only see the in-progress disassembly in GitHub, but you can see the end result too.

As well as the diary entries, I've also written about the tools that I use for my disassemblies. Spoiler alert: it's all extremely manual and the tooling is about as primitive as it can be. This is intentional.

Down the left-hand side of the table you can see my progression through the codebase. In big projects like this, I like to keep track of progress in minute detail; see the article on keeping track of progress for information about the documents and philosophies I use to get through such projects.

Finally, please note that this diary is a dump of my thoughts as I worked through The Sentinel, and as such it contains lots of mistakes and dead ends and misinterpretations. Sometimes it's terse; and sometimes it flows and meanders as I try to work things out by writing them down. This diary is all about the journey, rather than the destination; for the latter, see the finished product.
