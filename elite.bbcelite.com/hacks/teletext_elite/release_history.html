Details of every release of this hack and any issues you should know about

Teletext Elite has had the following releases:

  • 2022-12-03 - Initial release
  • 2022-12-09 - Fixed a bug where the bottom two lines of the mission briefing were showing as graphics rather than text
  • 2022-12-13 - Added circle-drawing optimisations from Michael Fairbank (thanks Michael!)
  • 2022-12-16 - Fixed a bug where the flight code would sometimes fail to load with a "Bad command" error
  • 2023-02-23 - Added flicker-free planets (to go along with the existing flicker-free ships)
  • 2026-09-05 - Added a mode 7 Acornsoft loading screen

You can check the release for a given disc image by loading the disc and typing *TYPE README to display the credits. The build date is at the end.

Known issues
------------

There are no known issues with this hack.
