Details of every release of this hack and any issues you should know about

The Universe Editor has had the following releases:

  • 2022-10-27 - Initial release (BBC version)
  • 2023-01-12 - Commodore 64 version released alongside an updated BBC version, with an improved file format to support both platforms, and various minor bug fixes for the BBC version
  • 2024-08-27 - Fixed a minor issue with the BOXART2 universe file that would make it take up more memory than required
  • 2026-09-02 - Commodore 64 version can now overwrite files when saving, and the 6502 Second Processor and Commodore 64 versions now display Dodo stations correctly just after file load (the BBC Master doesn't include this fix as there isn't enough room)
  • 2026-09-05 - Added a mode 7 Acornsoft loading screen to the BBC versions

You can check the release for a given BBC disc image by loading the disc and typing *TYPE README to display the credits. The build date is at the end.

For Commodore 64 disk images, there is a SEQ file on the disk called README that contains the build date.

Note that universe files saved from the initial 2022-10-27 release need to be converted to work in later versions. There is a BASIC program called B.CONVERT included on later versions to do this conversion. See the see the technical information for details

Known issues
------------

On the 6502 Second Processor version, explosions can leave some of their particles behind when deleted or selected (and striped ships like Thargoids and Morays can sometimes do the same). You can get rid of any unwanted explosion particles by simply changing to a different view and back again. This issue does not affect the BBC Master version, where explosions are better behaved.

As noted in the technical information, loading files that were created on the 6502 Second Processor version into the BBC Master version can be a bit hit and miss.

Finally, the BBC Master version displays stations in newly loaded files as Coriolis stations, even if they were Dodo stations when the file was saved (I tried to find space for the fix that sets the station type correctly, but I had to give up). Dodo stations should display correctly on the other versions.

If you find any bugs in the Universe Editor, then you can let me know via this Stardot thread or by emailing me. I'll see what I can do to help.
